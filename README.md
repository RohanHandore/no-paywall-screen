# Interview Coder - AI-Powered Coding Interview Assistant

A free, open-source desktop application that helps you prepare for coding interviews using AI. The app automatically detects programming languages from screenshots and provides instant solutions, explanations, and debugging assistance.

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- An API key from OpenAI, Gemini, or Anthropic

### Installation & Running

1. **Clone the repository:**
```bash
git clone https://github.com/RohanHandore/no-paywall-screen.git
cd no-paywall-screen
```

2. **Install dependencies:**
```bash
npm install
```

3. **Run the app:**

**Windows:**
```bash
stealth-run.bat
```

**macOS/Linux:**
```bash
chmod +x stealth-run.sh
./stealth-run.sh
```

4. **First Time Setup:**
   - Press `Ctrl+B` (or `Cmd+B` on Mac) to make the window visible
   - Open Settings and enter your API key
   - The app is ready to use!

## 📋 Essential Keyboard Shortcuts

- `Ctrl+B` (or `Cmd+B`) - Toggle window visibility
- `Ctrl+H` - Take screenshot of coding problem
- `Ctrl+Enter` - Process screenshots and get AI solution
- `Ctrl+R` - Start new problem
- `Ctrl+Q` - Quit application

## 💡 Use Cases & Why It's Helpful

### 1. **Real-Time Interview Assistance**
   - During live coding interviews, capture the problem statement and your code
   - Get instant AI-powered solutions with detailed explanations
   - Understand optimal approaches while solving problems

### 2. **Practice & Learning**
   - Practice coding problems from platforms like LeetCode, HackerRank, or Codeforces
   - Learn different solution approaches with time/space complexity analysis
   - Improve your problem-solving skills through AI-guided explanations

### 3. **Debugging Help**
   - Stuck on an error? Screenshot your code and error messages
   - Get structured feedback on bugs and optimization suggestions
   - Learn common mistakes and how to avoid them

### 4. **Language-Specific Learning**
   - **Automatic Language Detection**: The app automatically detects the programming language from your screenshots
   - Learn best practices for Python, JavaScript, Java, C++, Go, and more
   - Get language-specific code suggestions and patterns

### 5. **Discrete Assistance**
   - The window can be made invisible to most screen sharing tools
   - Works during remote interviews without being detected
   - Adjustable opacity for subtle reference during coding

## 🔧 How It Works

1. **Capture**: Take screenshots of coding problems using `Ctrl+H`
2. **Detect**: The app automatically detects the programming language
3. **Process**: Press `Ctrl+Enter` to get AI-powered analysis
4. **Learn**: Review solutions, explanations, and complexity analysis
5. **Debug**: Screenshot errors for instant debugging help

## 📝 Notes

- The app window is **invisible by default** - press `Ctrl+B` to toggle visibility
- All processing happens locally on your machine
- Your API key is stored securely and only used for API calls
- Supports multiple programming languages automatically
